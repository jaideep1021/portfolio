## 💻 Key Features

- **Interactive Shell Emulator:** Run real-time terminal commands (`cat profile.json`, `./show_stack.sh`, `ls awards/`, `clear`) with active audio click feedback.
- **Deep-Dive Case Study Modals:** In-depth technical architecture breakdowns with ASCII system diagrams, performance benchmarks, and implementation highlights.
- **Dual-Element Precision Cursor:** Custom modern spring-interpolated trailing cursor with dynamic mode toggle (**Modern** / **Retro CRT** / **System Default**).
- **Multi-Phosphor CRT Theme Engine:** Instant switching between **CRT Phosphor Green**, **Amber**, **Cyber Cyan**, and **Paper Light Mode** (with WCAG AAA contrast).
- **Matrix Digital Rain Canvas:** Hardware-accelerated background rain driven by `requestAnimationFrame`.
- **Zero-Dependency Vanilla Architecture:** Built with pure semantic HTML5, modern CSS3 (Custom Properties, Flexbox, CSS Grid), and lightweight vanilla JavaScript.

## 🚀 Local Development Setup

To run this portfolio locally on your machine:

```bash
# 1. Clone the repository
git clone https://github.com/jaideep1021/portfolio.git
cd portfolio

# 2. Serve locally with any static server
# Using Python:
python3 -m http.server 3000

# Or using Node:
npx serve .
```

Open `http://localhost:3000` in your browser.
